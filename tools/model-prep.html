Model prep

Turns a heavy .glb (for example one made with an image-to-3D tool) into a light one the game can load: fewer triangles, the colour texture saved as a separate JPEG, and a simple skeleton the game animates. Open this page through the game's server (py serve.py, then http://localhost:8765/tools/model-prep.html) to save straight into assets/models; otherwise use the download links.
