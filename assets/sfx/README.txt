Optional sound effect recordings
================================

Every sound in WATA SPO is generated by the game itself (js/audio.js), so this
folder can stay empty. To replace a sound with a real recording:

1. Put an .mp3 file here named after the sound, for example  hit.mp3
2. List the names you added in a file called  sfx.json  in this folder:

     ["hit", "pull5", "reward"]

The game reads sfx.json once when it starts and uses your files for those
sounds; everything else keeps the built-in sound.

Sound names
-----------
Interface: select, tap, back, whoosh, open, coin, reward, rewardItem, chest, levelup
Battle:    hit, crit, weak, break, heal, shield, buff, ult, ko, kill, finish, phase, win, lose
Members:   shot (Uruha), splat (Tsuna), sparkle (Sendo), dream (Noah), munch (Lisa), bonk (Hinano)
Recruit:   flip, pull3, pull4, pull5, ticket, rise

Keep files short (under 3 seconds) and trimmed so they start right away.
